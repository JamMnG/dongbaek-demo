# Dongbaek Demo

`dongbaek-demo` is a Vite + React landing page prototype for the Dongbaek demo concept. It presents a product-style narrative with a hero section, solution flow, mobile mockup, data pipeline summary, and a short closing rationale.

## Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Oxlint

## Run

```bash
npm install
npm run dev
```

## Checks

- `npm run build`
- `npm run lint`

## Notes

- The app currently uses a single-page React component in `src/App.jsx`.
- The design is driven by Tailwind utility classes and global styles in `src/index.css`.
